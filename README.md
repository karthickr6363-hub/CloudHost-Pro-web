# CloudHost Pro - Cloud Hosting Provider Landing Page

A modern, responsive landing page for a cloud hosting provider featuring unique design styles including Glass Morphism, Neomorphism, Modern Grid layouts, and Dark Mode with Neon accents.

## 🎨 Design Features

### Design Styles Used:
1. **Glass Morphism** - Hero section, Why Choose Us, Testimonials, Navigation
2. **Neomorphism** - Key Features cards, Pricing Plans, FAQ accordion
3. **Modern Grid + Flex Layout** - Services section, Integrations section
4. **Dark Mode + Neon Accents** - Real-time Performance Stats, overall theme

### Typography:
- **Primary Font**: Inter (Google Fonts)
- **Headings**: Space Grotesk (Google Fonts)
- **Monospace**: JetBrains Mono (Google Fonts)

## 📁 Project Structure

```
├── index.html      # Main HTML file with all sections
├── styles.css      # Custom SCSS/CSS for Neomorphism and additional styles
├── script.js       # JavaScript for interactivity
└── README.md       # This file
```

## 🚀 Features

### All 11 Required Modules:

1. ✅ **Hero Section** - Glass morphism design with CTA buttons and trust badges
2. ✅ **Key Features Section** - 6 neomorphism feature cards
3. ✅ **Services Offered** - Modern grid layout with 6 service types
4. ✅ **Pricing Plans** - 3-tier pricing with neomorphism cards
5. ✅ **Why Choose Us** - Glass morphism comparison cards
6. ✅ **Real-time Performance Stats** - Dark mode with neon accents
7. ✅ **Testimonials** - Glass morphism slider with auto-rotation
8. ✅ **Integrations/Tools** - Modern grid showing 8 integrations
9. ✅ **FAQs** - Neomorphism accordion with 8 questions
10. ✅ **CTA Banner** - Large call-to-action section
11. ✅ **Footer** - Complete footer with links, social media, and contact info

## 🎯 Interactive Features

- **Dark/Light Mode Toggle** - Persistent theme preference
- **Testimonial Slider** - Auto-rotating with manual controls
- **FAQ Accordion** - Expandable/collapsible questions
- **Smooth Scrolling** - Anchor link navigation
- **Animated Stats** - Real-time number animations
- **Parallax Effects** - Hero section parallax on scroll
- **Hover Effects** - Interactive cards and buttons

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework (via CDN)
- **Custom CSS/SCSS** - Neomorphism effects and custom styles
- **Vanilla JavaScript** - No dependencies, pure JS
- **Google Fonts** - Inter, Space Grotesk, JetBrains Mono

## 🚀 Getting Started

1. Open `index.html` in a modern web browser
2. No build process required - works directly in the browser
3. All dependencies are loaded via CDN

## 📝 Customization

### Changing Colors:
Edit the Tailwind classes in `index.html` or add custom CSS in `styles.css`

### Adding Content:
Simply edit the HTML content in `index.html` - all sections are clearly marked

### Modifying Animations:
Edit the JavaScript in `script.js` to customize animations and interactions
